# 🌱 Fresh Track — Stop Food Waste, Start Sharing

**Fresh Track** is a smart, user-friendly web application designed to help reduce food waste by allowing users to track food items, monitor expiry dates, identify food status, and donate surplus food to people in need.

The project was developed as part of **MIRAETHON 2K26 – Health & Wellness**.

---

## 🎯 Problem Statement

A significant amount of food is wasted because people forget about stored food, miss expiry dates, or do not know how to manage surplus food.

Fresh Track provides a simple digital solution to:

* Track food items
* Monitor expiry dates
* Identify food status
* Reduce unnecessary food waste
* Encourage food donation and sharing
* Visualize food management and impact

---

## 💡 Our Solution

Fresh Track provides a centralized dashboard where users can manage their food inventory and understand which items need attention.

The platform combines **food tracking, expiry monitoring, scanning, donation, and impact visualization** into one web application.

---

## ✨ Features

### 📦 Food Tracking

Add and manage food products with information such as:

* Product name
* Category
* Quantity
* Expiry date
* Food status

### ⏰ Expiry Monitoring

Track food based on its freshness and expiry status so users can prioritize items that need to be consumed soon.

### 📷 Food Scanning

The application includes a scanning/upload interface for extracting information from food labels.

### 🔍 OCR Support

The project uses **Tesseract.js** to perform Optical Character Recognition (OCR), helping extract text from uploaded food images.

### 📊 Dashboard & Analytics

The dashboard provides visual insights into food inventory and status using charts.

### 🤝 Food Donation

Surplus food can be made available for sharing and donation, helping connect excess food with people who need it.

### 🌍 Impact Tracking

The application presents food-saving and sharing information to encourage users to reduce food waste.

### 💾 Client-Side Storage

Food information can be stored locally using **LocalStorage**, allowing the application to work without requiring a traditional backend database.

## 🚀 How to Run

### Option 1 — Open Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No backend server is required for the basic client-side application.

### Option 2 — GitHub Pages

The project can be deployed using **GitHub Pages**.

1. Create a GitHub repository.
2. Upload `index.html`.
3. Make sure the file is named:

```text
index.html
```

4. Go to:

```text
Settings → Pages
```

5. Select the `main` branch and `/root` folder.
6. Save the settings.
7. GitHub will provide the deployed website URL.
